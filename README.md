# 猜数字小游戏（Guess the Number）

一个用 **Python 单文件** 实现的命令行小游戏：电脑随机想好一个 1~100 之间的整数，玩家不断猜，
电脑每次提示「大了」或「小了」，猜中后告诉玩家一共猜了多少次。

代码只有 32 行、带中文注释，非常适合作为**编程入门练手项目**。

## 功能特性

| 功能 | 说明 |
|---|---|
| 随机出题 | 每次启动都由电脑随机生成一个 1~100 的整数（含 1 和 100） |
| 大小提示 | 猜得比答案大提示「大了」，比答案小提示「小了」 |

## 代码逻辑说明

核心思路只有 4 步：

1. **出题**：用 `random.randint(1, 100)` 生成一个 1~100 的随机整数，保存到变量 `answer`。
2. **循环**：用 `while True` 持续询问玩家，直到猜中才退出。
3. **判断**：用 `if / elif / else` 比较大中小三种情况。
   - 玩家猜的数 **大于** 答案 → 打印「大了」
   - 玩家猜的数 **小于** 答案 → 打印「小了」
   - 两者 **相等** → 打印答案和总次数，然后 `break` 结束循环
4. **计数**：变量 `count` 每轮循环加 1，记录一共猜了几次。

关键代码片段：

```python
import random                          # 导入随机数模块

answer = random.randint(1, 100)        # 第 1 步：电脑随机出题
count = 0                              # 计数器

while True:                            # 第 2 步：一直问，直到猜中
    guess = int(input("请输入你猜的数字："))   # 读取键盘输入并转成整数
    count += 1                         # 第 4 步：次数 +1

    if guess > answer:                 # 第 3 步：三种比较
        print("大了")
    elif guess < answer:
        print("小了")
    else:
        print(f"恭喜你猜对了！答案就是 {answer}")
        print(f"你一共猜了 {count} 次")
        break                          # 猜中就跳出循环，程序结束
```

流程图（文字版）：

```
开始
 └─ 随机生成 answer (1~100)
     └─ count = 0
         └─ 循环：读取 guess → count+1 → 比较
             ├─ guess > answer → 输出「大了」→ 回到循环
             ├─ guess < answer → 输出「小了」→ 回到循环
             └─ guess = answer → 输出答案与次数 → 结束
```

## 变量一览

| 变量名 | 类型 | 作用 |
|---|---|---|
| `answer` | `int` | 电脑随机生成的答案（1~100） |
| `guess` | `int` | 玩家本次输入的数字 |
| `count` | `int` | 玩家已经猜了多少次 |

用到的两个知识点的简单解释：

- `input()` 读进来的一律是**字符串**，所以要用 `int(...)` 转成整数才能比较大小。
- `print(f"...{count}...")` 是 **f-string** 写法，能把变量的值直接嵌进字符串里显示。

## 常见问题

**1. 输入字母或直接回车会报错？**

会，程序会抛出 `ValueError: invalid literal for int() with base 10`，或者 `EOFError`。
因为 `int("abc")` 无法转换。当前版本**刻意不做输入校验**，目的是让初学逻辑更干净。
如果想更健壮，可以把循环开头改成：

```python
    text = input("请输入你猜的数字：")
    if not text.isdigit():          # 不是纯数字就提示重来，且不计入次数
        print("请输入一个整数哦～")
        continue
    guess = int(text)
    count += 1
```

**2. 中文显示成乱码怎么办？**

- 文件本身已声明 `# -*- coding: utf-8 -*-`，保存时请使用 UTF-8 编码。
- Windows 命令行如果出现乱码，可先执行 `chcp 65001` 切换到 UTF-8 代码页再运行。
- 输出重定向到文件时，可加环境变量：`set PYTHONIOENCODING=utf-8`。

**3. 猜一次就结束了，是不是有 bug？**

不是。如果第一次正好猜中，程序会直接输出答案并显示「你一共猜了 1 次」，这是正确行为。

**4. 为什么每次答案都不一样？**

因为每次启动都会重新执行 `random.randint(1, 100)` 随机取数。
如果想固定答案方便调试，可在 `import random` 后加一行 `random.seed(7)`。

## 可以自己改进的方向

按难度从易到难，建议依次尝试：

1. **输入校验**：非数字输入时提示重新输入，而不是报错退出（见上面的代码片段）。
2. **限定次数**：例如最多猜 7 次，用完还没猜中就提示「失败，答案是 X」。
3. **可以再玩一局**：猜中后问「再来一局吗 (y/n)」，把主逻辑包进一个 `while` 里。
4. **难度选择**：简单 1~50、普通 1~100、困难 1~1000。
5. **智能提示升级**：除了「大了/小了」，再提示「你离答案很近了」（差值 ≤ 5）。
6. **改成面向对象**：把答案、次数封装成一个 `GuessGame` 类，练习 `class` 写法。
7. **加记录榜**：把每次的最好成绩写入一个文本文件，下次启动时读取显示。

## 附：完整源码

```python
# -*- coding: utf-8 -*-
"""
猜数字小游戏
1. 电脑随机生成一个 1~100 的数字
2. 用户不断输入猜测的数字
3. 电脑提示 "大了" 或 "小了"
4. 猜中后告诉用户一共猜了几次
"""

import random  # 导入随机数模块

# 电脑随机出一个 1~100 的整数（含 1 和 100）
answer = random.randint(1, 100)

print("我想好了一个 1~100 之间的整数，你来猜猜看吧！")

count = 0  # 记录用户猜了多少次

while True:
    # 读取用户输入，并转成整数
    guess = int(input("请输入你猜的数字："))
    count += 1  # 每猜一次，次数加 1

    if guess > answer:
        print("大了")
    elif guess < answer:
        print("小了")
    else:
        # 相等就是猜中了，结束循环
        print(f"恭喜你猜对了！答案就是 {answer}")
        print(f"你一共猜了 {count} 次")
        break
```
